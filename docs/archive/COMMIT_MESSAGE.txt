feat: Initial implementation of Shopify Marketing AI Automation System

OVERVIEW:
Complete backend system for AI-powered Shopify marketing automation
including campaign management, AI content generation, and performance
monitoring across Meta and Google Ads platforms.

COMPLETED COMPONENTS:
- Backend API (Express.js + TypeScript)
- Database schema (Prisma ORM with PostgreSQL)
- API integrations (Shopify, Meta Ads, OpenAI)
- Background job processing (BullMQ + Redis)
- Campaign management service
- AI content generation service
- Approval workflow system
- Performance monitoring and optimization

ARCHITECTURE:
- Monorepo structure (backend, frontend, shared)
- RESTful API with Express.js
- PostgreSQL database with Prisma ORM
- Redis for job queue management
- OpenAI GPT-4 for content generation
- Automated background workers for metric syncing

INFRASTRUCTURE:
- Health check endpoints
- Error handling and logging (Winston)
- Rate limiting
- Security headers (Helmet)
- CORS configuration

API ENDPOINTS IMPLEMENTED:
- GET  /health - System health check
- GET  /api/campaigns - List all campaigns
- POST /api/campaigns - Create new campaign
- GET  /api/campaigns/:id - Get campaign details
- GET  /api/campaigns/:id/metrics - Get performance metrics
- POST /api/campaigns/:id/optimize - Get optimization recommendations
- POST /api/campaigns/:id/deploy - Deploy campaign to platform
- GET  /api/approvals - List pending approvals
- POST /api/approvals/:id/approve - Approve pending request
- POST /api/approvals/:id/reject - Reject pending request

DEPENDENCIES:
Backend: express, @prisma/client, bullmq, ioredis, openai,
         @shopify/shopify-api, winston, helmet, cors, zod
Dev: typescript, tsx, prisma, eslint, jest

CONFIGURATION REQUIRED:
- PostgreSQL database
- Redis server
- Environment variables (see .env.example)
- API credentials (Shopify, Meta, OpenAI)
