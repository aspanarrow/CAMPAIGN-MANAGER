# 📦 Historical Reports (archived)

The files in this folder are **stale, AI-generated status reports** from earlier
phases of this project (e.g. "FINAL_DEPLOYMENT_READY.md" claiming "Date: December
2024 — ✅ 100% READY", which predates the current code by ~2 years).

They describe a state of the repo that **no longer exists** and can mislead anyone
reading the project. They are kept here only for historical reference.

**Source of truth today:**
- `README.md` (root) — features + quick start
- `docs/` — active documentation
- `backend/.env.example` — all env vars
- Code comments — the code itself

If you need to find something from these old reports, search this folder, but
verify against the current code before trusting any claim.
