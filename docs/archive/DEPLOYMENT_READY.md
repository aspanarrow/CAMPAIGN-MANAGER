## 🚀 Quick Start (Production)

### Backend
```bash
cd backend
npm install
npx prisma generate
npx prisma migrate deploy
# Set environment variables
npm run build
npm start
# In separate terminal:
npm run worker
```

### Frontend
```bash
cd frontend
npm install
# Set environment variables (.env.local)
npm run build
npm start
```

### Environment Variables Required

**Backend (.env):**
- DATABASE_URL
- REDIS_URL
- API_KEY
- SHOPIFY_ACCESS_TOKEN
- OPENAI_API_KEY
- META_ACCESS_TOKEN (optional)
- META_AD_ACCOUNT_ID (optional)

**Frontend (.env.local):**
- NEXT_PUBLIC_API_URL
- NEXT_PUBLIC_API_KEY
